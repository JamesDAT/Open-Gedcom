# Experimental Roadmap

## API Lockin
The plan behind the current experimental is to reach a v1 api. Meaning that the Document class and its interfaces are decided on and implemented. The v1 does not have to have every feature possible, but at least the features that are implemented are finalised, this is to prevent breaking the api in future revisions.

## Implementation
Open Gedcom is built in a modular way so each implementation step can be modified. This experimental branch will not lock in any implementation details. It will provide a working implementation, but does not promise to be efficient or scalable. It will simply be the bare minimum to work.
